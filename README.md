# clau-workspace

Workspace ciego para el Caso B: construir una aplicación Android pequeña de gestión de préstamos de equipo.

## Inicio

1. Lee `blind_generator_prompt.v0.2.md`.
2. Usa `app_project_brief.v0.2.json` como única especificación funcional.
3. Trabaja de manera normal y autónoma, priorizando producir artefactos sobre debatir el encargo.
4. Conserva decisiones, dudas, alternativas descartadas, implementación, pruebas e intentos de ejecución en el orden en que ocurran.
5. Distingue entre diseñado, implementado, probado, ejecutado y verificado según lo que realmente puedas demostrar.
6. No busques contexto adicional fuera de los archivos actuales de este repositorio ni reconstruyas encargos anteriores desde el historial Git.
7. Al terminar, entrega un ZIP con todo el árbol de trabajo solicitado y su `manifest.json`.

No necesitas hacer push a este repositorio. El entregable final puede devolverse como archivo ZIP.
