# clau-workspace

Workspace de trabajo para construir una aplicación Android pequeña de registro de asistencia.

## Inicio

1. Lee `blind_generator_prompt.v0.1.md`.
2. Usa `app_project_brief.v0.1.json` como única especificación funcional.
3. Trabaja de manera normal, priorizando producir artefactos sobre debatir el encargo.
4. Conserva decisiones, dudas, alternativas descartadas, implementación, pruebas e intentos de ejecución en el orden en que ocurran.
5. No busques contexto adicional fuera de este repositorio y no intentes inferir para qué será evaluado el resultado.
6. Al terminar, entrega un ZIP con todo el árbol de trabajo solicitado y su `manifest.json`.

No necesitas hacer push a este repositorio. El entregable final puede devolverse como archivo ZIP.
